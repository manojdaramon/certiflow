# Project Instructions

This repository contains CertiFlow, a Skilling Certificate Issuance Platform built for a hackathon.

Before implementing any feature:

1. Refer to `docs/problem-statement.pdf` for the original functional and technical requirements.
2. Refer to `docs/implementation-plan.md` to understand the current development phase.
3. Follow the root and application-specific `AGENTS.md` instructions.
4. Inspect the existing code before modifying files.
5. Do not skip requirements or introduce unnecessary dependencies.
6. Do not implement multiple development phases at once unless explicitly requested.
7. Explain important technical decisions and ensure the generated code is understandable and testable.

The problem statement is the source of truth. If the implementation plan conflicts with it, follow the problem statement and highlight the conflict.
